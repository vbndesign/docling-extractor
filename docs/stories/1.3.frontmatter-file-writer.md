## Story

**As** the backend,
**I want** a deterministic component that takes (markdown_body, metadata, source) and produces a final `.md` file written to the output dir with the correct filename and frontmatter,
**so that** the output always respects the "minimum frontmatter" rule and naming convention without ambiguity.

## Acceptance Criteria

1. `backend/frontmatter.py` expõe função `build(metadata, source, now) -> str` que retorna o YAML frontmatter como string (delimitado por `---`).
2. Os seguintes campos DEVEM sempre estar presentes no YAML gerado: `note_type: literature_document`, `created` (YYYY-MM-DD), `extracted_at` (ISO 8601 com timezone), `location` (URL ou nome do arquivo original), `generated_by: docling`.
3. Os seguintes campos DEVEM estar presentes **somente se** vieram preenchidos no dict `metadata`: `source_title`, `author`, `year`. Se ausentes, omitir completamente — nunca incluir como string vazia, null ou placeholder.
4. Os campos `title`, `source_type`, `domain`, `concepts_extracted` **nunca** são gerados pela tool.
5. Valores com caracteres especiais (aspas, colons, caminhos Windows com barras invertidas) são corretamente escapados no YAML usando `yaml.safe_dump` ou equivalente.
6. `backend/file_writer.py` expõe função `save(frontmatter_str, markdown_body, metadata, source, output_dir) -> Path` que: (a) concatena `frontmatter_str + "\n" + markdown_body`, (b) deriva o nome do arquivo pela ordem de prioridade definida em FR7, (c) aplica slug kebab-case ASCII, (d) escreve no `output_dir`, (e) retorna o Path absoluto do arquivo criado.
7. Se um arquivo com o mesmo nome já existir no output, o writer adiciona sufixo numérico incremental (`-2`, `-3`) em vez de sobrescrever silenciosamente.
8. Testes unitários em `tests/test_frontmatter.py` cobrem: todos os campos condicionais presentes, todos ausentes, combinações mistas, e verificação de que campos proibidos nunca aparecem.
9. Testes do file_writer cobrem as 3 origens de nome (title, filename, URL slug) e o caso de colisão com sufixo incremental.

### Frontmatter Schema

[Source: arch §5.2, PRD §6 Story 1.3 AC2/3/4]

**Sempre presente:**
```yaml
note_type: literature_document
created: 2026-04-18                     # YYYY-MM-DD, data local
extracted_at: 2026-04-18T14:32:11-03:00 # ISO 8601 com tz
location: https://example.com/article   # URL ou filename (vem de source.location)

```

**Se detectado (senão omitir):**
```yaml

```

**Proibido gerar:** `title`, `source_type`, `domain`, `concepts_extracted` (FR5).

### Interface Contract — `build`

[Source: arch §6.3]

```python
def build(
    metadata: ExtractedMetadata,
    source: SourceDescriptor,
    now: datetime,
) -> str:
    """Retorna string '---\\n<yaml>---' pronta para concatenar ao markdown."""
```

- `now` é parâmetro (não `datetime.now()` interno) — determinístico e testável.
- `now.date().isoformat()` → campo `created`.
- `now.isoformat()` (com tz) → campo `extracted_at`. Garantir que `now` chegue tz-aware (caller responsável em Story 1.4).

### Filename Derivation (FR7 + arch §5.1)

**Ordem de prioridade:**
1. `metadata.source_title` (se `not None` e não vazio após strip)
2. `source.original_filename` (stem, sem extensão) — quando `source.kind in {"pdf_upload", "pdf_local_path"}`
3. Slug derivado da URL (`source.location`): pegar último segmento do path; se vazio, usar host.

**Transformação:**
- `python_slugify.slugify(raw, separator="-", lowercase=True, max_length=200)`
- Fallback R9 (slug vazio): `f"document-{int(now.timestamp())}"` (Story 1.4 passará `now`; nesta story, basta aceitar um parâmetro opcional `now` no writer ou gerar via `datetime.now()` no fallback — preferir receber `now` para testabilidade).

### Collision Handling

[Source: arch §2.2 R6 + PRD §6 Story 1.3 AC7]

Usar `Path.open('x', encoding='utf-8')` (mode `x` = exclusive-create, `FileExistsError` se já existir). Loop:

```python
base = slug
ext = ".md"
n = 1
while True:
    candidate = output_dir / (f"{base}{ext}" if n == 1 else f"{base}-{n}{ext}")
    try:
        with candidate.open("x", encoding="utf-8") as f:
            f.write(content)
        return SaveResult(output_path=candidate.resolve(), filename=candidate.name)
    except FileExistsError:
        n += 1
```

Isso é TOCTOU-safe (arch §2.2 R6).

### Edge Cases

[Source: arch §2.2 R5, R9]

- **Slug > 200 chars (R5):** truncar ANTES do sufixo de colisão e extensão. Windows NTFS trava em nomes >255 chars.
- **Slug vazio (R9):** fallback `document-{timestamp}`.

### Boundary Rules

[Source: arch §10.3]

- `file_writer` levanta `DoclingExtractorError` (ou subclasse `InternalError`) só se operação de disco falhar por motivo não-colisão. Nunca `HTTPException`.
- `frontmatter` é função pura — não levanta exceptions de domínio; erros de serialização YAML são bugs que devem aparecer nos testes.
